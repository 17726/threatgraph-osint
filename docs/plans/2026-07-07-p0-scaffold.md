# P0 脚手架 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 搭建 ThreatGraph-OSINT 的 P0 可运行脚手架，覆盖 FastAPI、SQLite seed、基础图谱 API、React 前端和 Docker Compose。

**Architecture:** 后端以 FastAPI 暴露 `/api/v1` 接口，SQLite 作为唯一事实源，启动或 seed 命令初始化演示数据。前端使用 Vite + React + TypeScript 调用后端 API，以 ECharts 展示基础知识图谱和报告内容。

**Tech Stack:** Python 3.14、FastAPI、pytest、SQLite、React、TypeScript、Vite、ECharts、Docker Compose。
