# 关系图谱展示深度与快速布局设计

日期：2026-07-17

## 目标

在“关系图谱”标题右侧增加可编辑的展示深度输入框，深度范围为 1–20，并让该深度同时作用于目标组织主图谱和节点邻居图谱。深度变化后实时刷新图谱；图谱数据更新后尽快停止力导向布局，帮助用户快速查看新图细节。

## 方案

前端复用后端已有的 `depth` 查询参数，不修改 API 契约。`fetchGraph` 增加 depth 参数并请求 `/graph?target=...&depth=...`；`fetchNeighbors` 增加 depth 参数并请求 `/graph/neighbors?entity_id=...&depth=...`。

页面维护当前有效深度和输入值。默认有效深度为 2。输入内容为空或非数字时显示校验提示且不发起请求；可解析数字小于 1 时限制为 1，大于 20 时限制为 20，随后使用限制后的值实时刷新。切换目标组织时沿用当前深度。若当前正在展示邻居图谱，深度变化重新请求当前选中节点的邻居图谱，否则请求当前目标组织主图谱。请求取消与请求状态判断用于避免旧响应覆盖新响应。

图谱刷新后通过 ECharts 实例停止 force 模拟，并适当缩短布局迭代周期；保留拖拽、缩放和漫游交互。

## 验收标准

- “关系图谱”标题右侧可见数字输入框，默认显示 2。
- 输入 1–20 的整数后，主图谱或当前邻居图谱实时按该深度刷新。
- 输入小于 1 或大于 20 时自动显示边界值 1 或 20 并刷新。
- 空输入或非数字输入显示“请输入 1–20 的整数”类提示，不发起无效请求。
- 主图谱和邻居图谱请求均携带 depth 参数。
- 新图加载后力导向布局快速停止，用户仍可拖动节点及缩放图谱。
- 现有前端测试、构建和格式检查通过。
